# Aura-Health-Hardware-STM32F401CC
The AURA Health system uses an STM32F401 MCU to process data and control peripherals via ADC, I2C, SPI, GPIO, UART, and DMA.  Sensors: Pulse (PA0/ADC1), MPU-6050 IMU (I2C)  Outputs: ST7789 TFT (SPI1), 7-Segment, 8x8 LED Matrix, Buzzer, 8-bit R-2R DAC  Controls: Navigation Button (PA8), Battery Monitor
